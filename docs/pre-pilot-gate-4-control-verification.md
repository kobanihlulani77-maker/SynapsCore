## Required Next Work For Acceptance

To accept Gate 4, the project still needs:

1. Use the generated inventory as the source of truth.
2. Group the 201 controls by route and domain.
3. Execute every reachable control under the correct role.
4. Verify disabled-by-design controls are truly disabled.
5. Verify role-restricted controls with a negative role test or backend rejection.
6. Verify every input, select, checkbox, and textarea changes state correctly.
7. Verify mutation controls through API readback, persisted GET response, or database-safe supported API result.
8. Verify representative double-submit and loading/error recovery paths.
9. Record a final classification for every `CTRL-###`.
10. Reconcile the arithmetic to zero unverified controls.
11. Run backend tests, frontend lint/build/verify, secret scan, docs link check, diff check, and hosted proof.
